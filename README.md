## Призначення

Консольна програма зберігає ім'я, прізвище, групу та середній бал
студента. У меню доступні додавання, перегляд списку, пошук за групою,
визначення найкращого студента, середній бал групи та рейтинг.
Використано src-layout, dataclass, type hints і три основні модулі.

## Вимоги та встановлення

Потрібен Python 3.11 або новіший і Git. Виконуйте команди з каталогу,
у якому лежить pyproject.toml. Спочатку розпакуйте архів.

```console
python --version
python -m venv .venv
```

Активація у Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Активація у Windows cmd:

```bat
.venv\Scripts\activate.bat
```

Активація у Linux/macOS:

```bash
source .venv/bin/activate
```

Після активації:

```console
python -m pip install -e ".[test]"
python -m pip list
python -m student_manager.main
```

Альтернативна команда запуску: `student-manager`.
Якщо PowerShell блокує активацію, можна обійтися без неї:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m student_manager.main
```

## Приклад роботи

Натисніть `1` і введіть чотири значення:

```text
Ім'я: Марія
Прізвище: Дорош
Група: ФЕП-32
Середній бал (0–100): 86,5
Додано: Дорош Марія.
```

Так само додайте Данила Левицького (ФЕП-31, 95) та Соломію Климчук
(ФЕП-32, 91,5). Це вигадані дані для перевірки, а не реальні оцінки.
Пункт `2` виведе всі записи. Пункт `3` з групою `феп-32` знайде двох
студентів. Пункт `4` покаже Данила Левицького з балом 95,00.
Пункт `5` для ФЕП-32 обчислить (86,5 + 91,5) / 2 = 89,00.
Пункт `6` виведе рейтинг, пункт `0` завершить програму.

Програма не містить готового списку: кожен запуск починається з порожнього
реєстру. Дані зберігаються тільки в оперативній пам'яті до виходу.
Прийнято шкалу 0–100. Дозволені крапка або кома як десятковий роздільник.
Порожні поля, нечислові значення, NaN, нескінченність і бали поза шкалою
відхиляються. Для відсутньої групи виводиться повідомлення, а не нульовий
середній бал. Якщо максимальні бали однакові, обирається перший доданий
студент із таким балом. Пошук групи не враховує регістр і крайні пробіли.

## Структура

- `src/student_manager/models.py` — Student та перевірка даних.
- `src/student_manager/services.py` — операції зі списком і обчислення.
- `src/student_manager/main.py` — введення, меню та виведення.
- `src/student_manager/__init__.py` — позначення пакета та його версія.
- `tests/test_services.py` — перевірки операцій і граничних значень.
- `pyproject.toml` — метадані, збирання, команда запуску та pytest.
- `.gitignore` — винятки для локальних і згенерованих файлів.
